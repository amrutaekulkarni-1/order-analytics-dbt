# Order Analytics with dbt and DuckDB

## Project Overview
This project analyzes order data using dbt, SQL, and DuckDB.

## Objectives
- Analyze revenue and net order value.
- Calculate discounts by customer tier.
- Identify delayed and high-value orders.
- Compare order performance across regions and months.
- Implement data quality tests.

## Technology Stack
- SQL
- dbt
- DuckDB
- Visual Studio Code
- GitHub

## Project Status
Setup and development in progress.
